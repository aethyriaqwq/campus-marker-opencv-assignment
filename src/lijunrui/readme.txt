白色发光装甲板四角点识别

使用了c++17和opencv，主要流程为滤波，二值化，形态学处理，轮廓提取，获取发光条的六角点并进行形态判断，最后进行灯条的匹配

1.构建与运行
    需要 CMake 3.16 及以上版本、C++17 编译器和支持 MP4 读写的 OpenCV 4 开发包。

    请将CMakeLists.txt置于项目文件夹下
    cmake -S . -B build
    cmake --build build -j
    ./build/detector_demo data/raw/marker_video.avi results/output.mp4

    每段视频会输出以下内容，全部与输入视频保持相同帧率，由 OpenCV 的 `VideoWriter` 直接写为 `mp4v` 编码的 MP4。程序不再进行外部转码；
    新生成的视频可能无法在 VS Code 内置播放器中直接打开，可使用支持 MPEG-4 Part 2 的播放器查看。

    读取的视频为 data/raw/marker_video.avi
    生成的视频保存在 results/optput.mp4

2.流程与参数
    主体思路：只关注四角上的 “L” 型灯条，使用它们的外顶点（较准确）进行主要匹配，使用内顶点（有误差）进行辅助匹配，
             其余角点只用于判断灯条形状

    名词的说明：灯条为 “L” 型，有六个角点
        1.中间直角部分靠外的称为外顶点（即装甲板的四个顶角），靠内的为内顶点（inner_keypoint）
        2.灯条两端，我们记垂直于x轴的为 边1 ，两端点为 outer_sidepoint1 , inner_sidepoint2
          边二同理，inner_sidepoint统称内角点，outer_sidepoint统称外角点
    
    流程：
    1.滤波：采用 3*3 的中值滤波
    2.二值化：将bgr均大于min_color的设为 1
    3.形态学处理：先闭运算后开运算，均使用 3*3 kernel
    4.轮廓提取：使用findContours得到外轮廓上的若干关键点
    5.获取灯条角点：
        ①先获取外顶点和两端的外教点
            我们获取灯条外接矩形，则外顶点和两个外角点一定在矩形四角上
            但不难发现灯条的角在视频中为锯齿状的，所以一个角上可能会有多个点被识别进了轮廓
            我们取所有这样的点，进行排序，并去重
            我们通过外顶点的x等于其中一个外角点的x，外顶点的y等于另一个外角点的y，可以判断出三个点中哪个是外顶点
            再进行一些操作使外顶点的坐标更准
        ②判断灯条位于哪个角上
            直接根据外顶点和外角点的相对位置判断即可
            我们记灯条的 type 等于 1到4 分别表示：左上、右上、右下、左下
        ③再获取两端的内角点
            分别去 “L” 型两端的边上的端点，一个是已知的外角点，则另一个是内角点
        ④最后获取内顶点
    6.灯条匹配：分别取出每种type的角点判断能否形成矩形即可
        
3.其他说明：
    同时识别灯条六角，准确率较高，因此不需使用太多先验的条件进行判断，对轮廓的面积判断 和 二值化的过滤下限较高
    仅为使输出的视频无被误识别为灯条的光斑，更干净
    即使不进行先验的判断，这些光斑也不会与正常灯条相匹配
