# 标志物识别方法报告

## 1. 目标与整体流程

目标是在连续帧中识别校内赛标志物，给出发光图案外缘区域及 LT、RT、RB、LB 四个顶点，并在无目标时及时返回未检测到。

流程为：读入当前帧 → 灰度化与二值化 → 提取外轮廓 → 筛选亮角候选 → 枚举三个候选的几何组合 → 预测右上位置 → 检查并测量右上碎片 → 校验四点顺序与凸性 → 绘制并保存结果。

算法利用标志物三个较完整亮角和右上碎片区域的布局，不使用深度学习。

## 2. 主要步骤与函数

### 候选区域提取（main）

使用 `cvtColor(..., COLOR_BGR2GRAY)` 转换灰度，使用固定阈值 120 将较亮像素设为白色。`findContours` 提取外轮廓，轮廓面积小于 80 像素平方时排除。

对每个轮廓使用 `minAreaRect` 拟合最小面积旋转矩形，以较长边与较短边之比计算长宽比，以轮廓面积除以矩形面积计算填充率。长宽比过大的细线被排除；填充率帮助区分稀疏区域、近实心区域与亮角候选，但并不能严格证明其为 L 形。

### 三角组合检查（checkTriple）

枚举三个不同候选，分别假设为左上、左下和右下。以左下为公共端点，计算向量 u = LT − LB、v = RB − LB。

排除过短向量、两边长度差异过大的组合；通过归一化点积检查两向量是否近似垂直。随后使用 RT = LT + RB − LB 预测右上中心。这是平行四边形近似，对强透视不够准确。

### 外缘角点（selectOuterCorner、locateOuterCorners）

用三个候选中心及预测右上中心的均值估计整体中心。对单个候选旋转矩形的四个顶点，计算其沿“整体中心指向该候选中心”方向的点积，选择最大者作为外侧角点。

输出采用 LT、RT、RB、LB 顺序。右上外角先预测，再由局部测量替换。这里选取的是旋转矩形顶点，属于外缘近似，不保证完全落在原始轮廓上。

### 右上碎片测量（measureRightTop）

以预测右上中心建立搜索窗口，检查白像素占比。窗口必须完整位于图像内。对窗口中的轮廓过滤小碎片，要求至少两块有效碎片。

将局部轮廓点加上窗口左上角坐标，还原为原图坐标；合并有效碎片点并拟合旋转矩形，选择其外侧角点。实测点若偏离预测外角过远则排除组合。

### 顺序与凸性（validCornerOrder）

检查上、下两边的左右关系及两侧的上下关系，要求边长足够，并通过连续边的二维叉积检查凸性和转向一致。这减少了同一位置被不同标签解释的问题，但不等价于全局去重。

### 连续帧与输出（main）

每帧重新创建候选和识别结果，仅根据当前帧整体候选是否为空决定检测状态。没有无限沿用上一帧结果，也没有加入显式时序平滑或追踪。

所有通过检查的整体候选都绘制到原图副本，并写入结果视频。程序未实现最佳候选评分或重复候选合并。

## 3. 关键参数

| 参数 | 当前值 | 用途 |
| --- | --- | --- |
| 灰度阈值 | 120 | 分离亮区与暗背景 |
| 单区域最小面积 | 80 px² | 排除小噪声 |
| 候选最大长宽比 | 4.0 | 排除过细长区域 |
| 候选填充率 | 0.15～0.80 | 筛选亮角候选 |
| 三点两边最小长度 | 10 px | 排除过近组合 |
| 三点两边最大长度比 | 2.0 | 限制几何比例 |
| 归一化点积绝对值上限 | 0.3 | 要求近似垂直 |
| 右上搜索半径 | max(10 px, round(平均候选长边 × 0.65)) | 适应局部尺度 |
| 搜索窗口白像素占比 | 0.04～0.65 | 排除过暗或过亮窗口 |
| 有效碎片最小面积 | max(4 px², 窗口面积 × 0.005) | 排除小碎片噪声 |
| 有效碎片数量下限 | 2 | 验证右上存在多个亮区 |
| 实测右上最大偏差 | 平均候选长边 × 0.6 | 约束测量位置 |
| 最终四边形最小边长 | 10 px | 排除退化区域 |

这些参数是开发调试使用的经验值，不是跨场景最优值。固定像素阈值会受分辨率和目标距离影响；填充率、比例与点积约束相对更便于跨尺度使用。

## 4. 已观察问题与验证结果

开发中曾观察到细线被候选框选，通过输出长宽比、填充率和筛选状态定位问题，并增加对应筛选。轻微晃动时曾出现同一个顶点被不同标签重复标注的问题，加入四点顺序和凸性约束后，开发者反馈该现象已解决。

本机环境：Ubuntu 22.04.5 LTS、g++ 11.4.0、CMake 3.22.1、OpenCV 4.10.0、C++17。

开发者报告本机编译成功，完整视频的人工检查通过：目标清晰时识别连续；轻微晃动时四点顺序稳定；无目标时旧目标框消失；保存结果视频可播放并包含标注。未提供定量检测准确率、误检率或角点误差统计。

由于没有摄像头，摄像头输入未实测。未进行相机标定和位姿估计。

## 5. 已知限制与改进方向

- 目标姿态：当前上下、左右判断及平行四边形近似适合大致正立、透视不强的目标。大角度旋转和强透视下可能失败，可进一步采用方向一致性或更完整的几何模型。
- 亮度与尺度：固定灰度及面积阈值在曝光变化、远距离和不同分辨率下可能失效，可先比较不同场景的二值图，再考虑自适应阈值与尺度相关参数。
- 右上结构：目前只要求至少两块有效碎片，没有验证完整排列；窗口中其他亮区可能影响测量，碎片合并也可能导致漏检。
- 图像边界：搜索窗口不完整时直接排除，因此目标接近边界或部分离开时可能提前返回未检测到。
- 重复候选：顺序检查不能保证消除所有重复组合，后续可按四角距离或区域重叠合并，并用几何评分选择结果。
- 时间稳定性：目前逐帧独立检测，未显式平滑。若出现抖动，可先解决单帧误检，再加入匹配与有限平滑，同时保证无当前帧证据时清除过期结果。
- 运行开销：n 个候选采用三重枚举，组合阶段约为 O(n³)，复杂亮背景可能明显增加耗时。

上述限制中，除已记录的开发问题外，其他为根据实现推导的潜在失效条件，未声称均已实测。后续优先用现场连续帧检查这些条件，再决定是否增加复杂流程。
