# RM 校内赛标志物识别 - 技术报告 (REPORT)
## 1. 项目概述
本项目基于 C++ 与 OpenCV 传统视觉方法，完成了校内赛标志物（发光 L 型组合）的识别与位姿估计。整体采用面向对象（OOP）架构，将检测、可视化、时序状态管理、相机标定与 PnP 解算解耦。必做部分实现了连续帧下的稳定检测与目标丢失处理，挑战部分基于圆点标定板完成了相机标定，并实现了标志物的 3D 位姿解算。

## 2. 必做部分：标志物识别
### 2.1 方法流程
图像预处理：将原图转换为灰度图，利用 cv::inRange 提取高亮发光区域（发光 L 型）。由于四个 L 型之间存在黑色间隙，形态学闭运算难以在不变形的前提下将它们连接，因此策略改为仅使用 cv::morphologyEx 进行开运算去噪，保留每个 L 型的独立轮廓。

轮廓提取与几何筛选：通过 cv::findContours 获取所有轮廓，基于面积（> 100 像素）和长宽比（0.5 ~ 2.0）过滤掉噪点和无关物体。

区域聚合与顶点提取：遍历所有符合条件的 L 型轮廓，收集其所有像素点，利用 cv::minAreaRect 拟合整体正方形，使用 cv::boundingRect 获取水平外接框。

顶点排序：计算四个顶点的几何中心，根据坐标象限将顶点稳定排序为 LT, RT, RB, LB（左上、右上、右下、左下），确保后续 PnP 解算的顺序一致性。

### 2.2 时序稳定与状态机（防闪烁）
为满足“无目标时不无限复制上一帧结果”与“检测连续无明显闪烁”的要求，在 VideoProcessor 中设计了一个状态机：

LOCKED（完整锁定）：目标完整可见，连续检测帧数超过 MIN_DETECT_FRAMES (3帧) 时更新坐标。

LOST（彻底丢失）：目标完全消失，且丢失计数器 lostFrames_ 超过 MAX_LOST_FRAMES (15帧) 时，清空历史结果并输出丢失提示。

### 2.3 关键参数
参数	数值	说明
亮度阈值	200 ~ 255	提取高亮发光区域，需根据环境光调整
形态学核	3x3 矩形	开运算去噪，避免大核导致 L 型变形
最小面积	100 像素	过滤背景噪点
状态机帧数	MIN=3, MAX_LOST=15	平衡响应速度与抗闪烁能力
### 2.4 失败案例与改进思路
失败案例：最初尝试使用大尺寸形态学闭运算（如 15x15 或更大）将四个 L 型连接成一个整体正方形，但在实际测试中发现，这会导致正方形边缘严重变形，四个角的顶点提取出现巨大误差。

改进思路：改为“分而治之”策略。不再强求形态学连接，而是分别收集独立的 L 型轮廓像素，再通过 minAreaRect 计算整体外接矩形。这不仅保留了角点精度，还使得算法在部分 L 型被遮挡或出画时依然能大致框出目标位置。

## 3. 挑战部分：相机标定与位姿估计
### 3.1 相机标定
标定板类型：圆点阵列标定板（型号 HC300-15-7x7），7x7 阵列，圆心间距 0.03m。

数据来源：从 calibration_video.avi (1440x1080, 70FPS) 中每 30 帧抽取一帧，共采集 20 张有效图片进行标定。

内参与畸变来源：使用 cv::findCirclesGrid 提取圆心，调用 cv::calibrateCamera 解算。最终得到相机内参矩阵与畸变系数，重投影。

参数缓存：标定结果保存为 camera_params.yml。后续运行程序时自动读取该文件，跳过标定视频处理，将运行时间从分钟级降至秒级。

### 3.2 标志物位姿估计 (PnP)
坐标系定义：

标志物坐标系：原点位于标志物正方形外框中心，X 轴向右，Y 轴向下，Z 轴垂直标志物向外。四个顶点 3D 坐标为 (-L/2, -L/2, 0)、(L/2, -L/2, 0)、(L/2, L/2, 0)、(-L/2, L/2, 0)。由于未提供实物尺寸，本项目中假设边长 L = 100mm。

相机坐标系：以相机光心为原点，X 轴向右，Y 轴向下，Z 轴指向相机前方。

解算流程：利用 MarkerDetector 输出的四个顶点 2D 像素坐标，结合上述 3D 坐标与标定内参，调用 cv::solvePnP 解算旋转向量与平移向量。

可视化：使用 cv::projectPoints 将 3D 坐标轴投影回图像，绘制红（X）、绿（Y）、蓝（Z）三色坐标轴，并输出相机到标志物的距离 cv::norm(tvec) (单位：mm)。

## 4. 性能优化与运行说明
标定缓存：避免每次运行都重新处理 6966 帧标定视频，首次标定后直接读取 camera_params.yml。

## 5. 已知限制与未来改进
物理尺寸假设：由于未拿到标志物实物，3D 坐标中假设边长为 100mm，因此解算出的距离数值是一个相对比例值（若实际边长为 200mm，距离数值也会翻倍）。未来可通过实际测量校准该参数。

光照鲁棒性：传统视觉的二值化阈值对光照变化较为敏感。当前参数在实验室光照下表现良好，但在强逆光或极暗环境下可能失效。未来可考虑引入 cv::adaptiveThreshold 或 OTSU 算法自动调节阈值。

透视形变：当标志物倾斜角度过大时，minAreaRect 拟合的顶点精度会下降，未来可尝试在预处理阶段加入透视校正（cv::warpPerspective）。
