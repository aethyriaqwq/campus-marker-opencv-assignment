# 校内赛标志物识别实验报告

杨冉星 · 50032560

## 一、任务与目标区域

输入是相机连续 BGR 帧，输出是当前帧的目标存在性、区域、四角和可视化。设计依据为仓库 `docs/assets/marker_dimensions.jpg`：三个完整 L 形灯带，一个断开的角灯，内部为暗区。采用传统图像处理，无训练权重、帧号查表或人工逐帧标注。

关键点选取灯带图案的四个外角，其围成尺寸图中的 80×80 范围。黑色安装壳体在测试画面中有额外延伸，外形也不是标准四边形，因此不将壳体轮廓混入灯带角点。识别仅使用相对比例 80/30、8/80 等，不假定尺寸单位，也不输出三维距离。

## 二、方法流程

### 1. 工作图与亮度分割

为控制计算量，将宽度大于 960 的输入按比例缩小，其他输入不放大。BGR 转灰度，阈值 180 提取高亮灯带，再做 3×3 矩形闭运算，连接压缩噪声造成的小孔隙。使用 `RETR_EXTERNAL` 提取轮廓，保存轮廓点用于后续边界拟合。

本素材灯带接近白色高亮而背景较暗，灰度对比比颜色更直接。阈值是显式可调参数，不代表适用于所有曝光。选闭运算而不是大尺度膨胀，是为了保留断角结构，并避免把邻近目标强行合并。

### 2. L 形候选与尺度推算

对每个连通轮廓计算面积和最小外接旋转矩形。用面积、边长比例及填充率排除小噪点、长条、实心亮块。完整 L 形由两条窄臂组成，填充率明显低于实心方块。

以旋转矩形的每个角作为可能的 L 外角，将两边按照 80/30 放大，生成一个完整图案的四边形假设。每个 L 独立提出候选，因此不必先把所有亮点聚为一个大连通域，也不会假设整幅图只有一个目标。错误方向会在后续验证中被剔除。

### 3. 外缘直线拟合与四角精化

初始假设受透视、光晕和旋转矩形近似影响。对每条候选外边，收集距离该边不超过平均边长 12% 的亮轮廓点，沿边分成 24 段，每段保留最靠外的点。用 `fitLine(DIST_HUBER)` 拟合外缘，邻边求交得到四角。

分段取最外点可减少灯带内边缘把拟合线拉向图案中心的情况。四条边独立拟合，不要求最终结果仍是旋转矩形。若支持点不足、交线近乎平行或角点改变量过大，则保留初始候选，仍必须接受当前帧图案验证。

### 4. 几何与图案双重验证

要求四边形凸、面积足够、边长不过度失衡、内角不过度尖锐，并且四个角完整位于图像内。将候选四边形透视变换为 160×160 二值图，与按尺寸示意图比例生成的理想灯带模板比较。模板直接由 C++ 矩形绘图生成，不从测试视频截取。

对四个 90° 旋转分别计算像素 F1：

`F1 = 2 × count(observed AND template) / (count(observed) + count(template))`。

除总分不低于 0.64，还要求每个角区有足够的模板重合像素，以及中心暗区的亮像素比例不超过 10%。这样可排除普通亮矩形、四个孤立亮块，以及明显缺角的候选。仅有几何关系而没有当前图案证据时不输出。

### 5. 去重与跨帧稳定

候选按相似度降序排列，先通过中心距离及尺度关系抑制近乎重合的重复候选，再按多边形重叠面积抑制重复区域。开发中观察到 OpenCV 4.12 在第 619 帧的极接近四边形上出现一次重复保留；中心/尺度门限消除了对多边形求交数值精度的依赖，并加入真实帧回归测试。

通过中心距离和尺寸变化关联相邻帧。只有当前帧通过完整检测后，才可能与前帧的同一目标进行指数平滑：`p = 0.75 × current + 0.25 × previous`。角点运动超过目标边长 8% 时使用当前观测，减少高速运动拖尾。未匹配目标不输出，空帧立即清空轨迹。这里不使用丢失帧预测或无限延用。

### 6. 排序、坐标和输出

点先按绕中心的角度排序，再以 x+y 最小点作为 LT；得到 LT→RT→RB→LB。将工作图坐标分别乘以 `original_width/work_width`、`original_height/work_height`，避免尺寸取整造成横纵误差。程序不裁剪 ROI，不依赖固定目标位置。

可视化及 CSV 全部使用原图像素坐标。四边形作为目标区域，CSV 同时给出轴对齐外接框；不存在目标时坐标留空。输入分辨率改变时清除旧轨迹，防止不同坐标系的结果混合。

## 三、关键参数

| 参数 | 默认值 | 选择依据与影响 |
|---|---:|---|
| 工作宽度 | 960 px | 降低处理量，同时保留该视频中灯带厚度 |
| 灰度阈值 | 180 | 分离白色灯带和暗背景；低曝光可能需要下调 |
| 闭运算核 | 3×3 | 修补局部断点，不连接相距较远的灯带 |
| L 候选轮廓面积 | ≥35，≤图像面积6% | 排除小噪点和大块光照区域 |
| L 矩形短边/长短比 | ≥9 px / ≤2 | 去除细长或过小轮廓 |
| L 填充率 | 0.22～0.82 | 允许模糊变化，但排除接近实心的方块 |
| 假设放大倍数 | 80/30 | 来自示意图灯带跨度与 L 臂长度比例 |
| 四边形面积 | ≥500 px² | 避免远距离极小目标不稳定拟合 |
| 四边最长/最短边比 | <2.3 | 允许适度透视，拒绝极端退化候选 |
| 邻边夹角余弦绝对值 | ≤0.7 | 排除近乎共线的角 |
| 外缘搜索带 | 平均边长的12% | 允许初始假设偏差 |
| 图案最低 F1 | 0.64 | 兼顾少量模糊与形状约束 |
| 每角模板覆盖率 | ≥42% | 防止缺角或随机亮点拼接 |
| 中心亮像素 | ≤250/2500 | 保证中心主要为暗区 |
| 关联中心距离 | <平均边长45% | 相邻帧关联范围 |
| 平滑权重 | 当前0.75，上一帧0.25 | 减少微小角点抖动，保留较快响应 |

像素阈值均作用于工作图。缩小工作宽度会提高可可靠识别的原图目标尺寸下限。

## 四、验证与结果

### 环境及测试方法

在 WSL2 Ubuntu 24.04.3 LTS、GCC 13.3.0、CMake 3.28.3 下编译。分别使用 Ubuntu 系统包 OpenCV 4.6.0 与已安装 OpenCV 4.12.0；源文件和 CMake 不包含本机绝对路径。

CTest 使用自动生成的透视图案验证坐标误差、不同处理尺寸、关联、离场即清除、遮挡、重新出现和多目标。原图角点容差设为 7 像素；该容差是测试上限，并非真实视频的角点误差测量值。还检查真实视频第 0、619、900 帧，防止重复候选和空场景回归。

### 仓库完整视频

输入：`data/raw/marker_video.avi`，1440×1080，容器帧率约 70.408336 FPS，1676 帧，总长约 23.804 秒。所有帧按顺序处理，无跳帧。

- 正检测帧 1086，未检测帧 590。未检测帧包含目标完全离场及四角不完整的边缘片段。
- 检测连续区间（包含端点）：0–35、127–264、275–421、471–800、972–1211、1393–1575、1664–1675。
- 这些连续区间内部没有空检测帧。程序没有把上一帧预测当作当前帧检测，连续性来自每帧图案验证。
- 开发初轮在 OpenCV 4.12 下测得检测部分平均约 5.1 ms/帧，OpenCV 4.6 下约 6.0 ms/帧。此数值不包含解码、写视频和窗口开销，不等于端到端摄像头性能保证；最终运行摘要见 `evidence/validation.txt`。
- 逐帧结果保存在 `evidence/frames.csv`，可以独立统计存在性、坐标和分数。

上述计数是程序输出统计，**不能视为精确率或召回率**。仓库没有逐帧人工真值，也没有现场测试集。本次结合连续区间、抽样图像和边界帧进行复核，没有声称完成独立泛化评测。

## 五、失败案例与已知限制

1. **部分离场/缺角**：例如第 36 帧，灯带右侧已被画面截断，但主体仍有一部分可见；程序不尝试猜测画面外角点，返回未检测到。这是保守完整性规则的结果，也是部分可见目标的漏检案例。第 900 帧为空场景，输出未检测到。
2. **遮挡或重叠**：程序支持分离的多个完整目标，但重叠目标可能只保留一个完整目标，缺角目标会被拒绝；不能承诺分离所有遮挡物体。素材中的重影/相邻外壳也不能据此直接当成多个完整目标。
3. **曝光和反光**：固定阈值在极暗环境、灯带熄灭、背景大面积过曝时可能失效；反光中出现相似完整图案时也可能误检。
4. **远距离和大透视**：灯带缩小到少量像素时，闭运算和最小面积门限会导致漏检；大透视下单 L 的矩形假设可能不足。
5. **大旋转的角标**：当前 LT 等是图像相对角名；接近对角线方向时，x+y 最小顶点可能切换，不保证同一物理角永远叫 LT。没有将其冒充 PnP 所需的物体固定角序。
6. **平滑及跟踪**：平滑可能带来少量延迟；遮挡、目标消失、多目标交叉会导致 ID 改变。ID 不是长期身份识别。
7. **现场输入**：摄像头入口已实现，但当前未连接实际设备做现场验收。测试环境是现有 WSL 安装，未把它描述为重新安装的干净系统。

## 六、改进方向

- 通过局部自适应阈值和多阈值候选提高曝光适应性，再用图案分数统一筛选。
- 为大透视引入多 L 之间的直线配对或单应性假设，并对严重退化情况输出明确状态。
- 建立独立的多场景真值集，测量精确率、召回率、四角像素误差和端到端延迟。
- 如果扩展位姿估计，应先确定标定板规格和尺寸单位，进行相机标定，再根据断角定义固定物体朝向；不能直接从曝光设置截图推断内参。

本次不包含选做的相机标定与位姿估计。没有输出相机内参、畸变、三维坐标轴或测距结果。
